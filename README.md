What's new: circular minimap icon (**click** to open; **Alt + drag** to move it outside the minimap ring), animated dice and coin tosses with a large on-screen result, and local chat announcements **after** the reveal. Existing win/draw/loss records are preserved.

A recreational World of Warcraft addon for **Coin Toss** (best of 1, 3, or 5) and **Deathroll** (start at d1000; alternate turns until someone rolls 1 and loses).

### Features
- **Scoreboard layout fixed:** the W/D/L panel stays inside the casino window, below Match History
- **Minimap button:** click to open/close, drag to move, `/casino map` to show, `/casino reseticon` to reposition
- **Local random rolls:** no waiting for WoW's `/roll` system messages
- **Career scoreboard:** saved wins, draws, and losses per character, separated into two-player and solo records
- **Mutual draws:** two-player opponents can offer and accept a draw
- Solo practice controls Side A and Side B; its record is from **Side A's viewpoint**
- Two-player invites, individual Ready confirmations, a draggable minimap button, and an 18+ self-confirmation screen
- No currency, transfer, or payment functions

**Important:** Random results are generated by each player's addon, not by the game server. A modified addon could manipulate them. This is designed for casual, trust-based games and not valuable wagers. An addon cannot install a tamper-proof server RNG.

### Install
1. Download the [latest ZIP](https://github.com/ChillxHunter/ForeverCasino/raw/refs/heads/main/ForeverCasino_v1.4.1_Minimap_Scoreboard_Fix.zip).
2. Extract its `ForeverCasino` folder to `World of Warcraft/_forever_/Interface/AddOns/`.
3. Remove any older `ForeverCasino` folder before extracting, then restart WoW Forever.
4. Open with `/casino` or the minimap button.

Both players need **v1.4.1** for multiplayer (addon protocol `FCasino4`). Only completed games count toward the scoreboard. No in-game server-side verification has been performed; Lua syntax, simulation of core gameplay, and UI tests passed.
