# Forever Casino — WoW Forever

**Current version:** 1.3.0

[Download ForeverCasino v1.3.0 ZIP](https://github.com/ChillxHunter/ForeverCasino/raw/refs/heads/main/ForeverCasino_v1.3.0.zip)

A recreational World of Warcraft addon with **Coin Toss** (best of 1, 3 or 5), **Deathroll** (d1000, alternate until someone rolls 1), **Solo Practice** and two-player challenges. Both players press **Ready** before two-player games. Includes a minimap launcher, a redesigned native UI, and an 18+ self-confirmation prompt.

## Install
1. Download the ZIP above.
2. Extract the `ForeverCasino` folder into `World of Warcraft/_forever_/Interface/AddOns/`.
3. Restart the game and enable Forever Casino in the addon list.
4. Type `/casino` or click its minimap icon.

**No currency, value transfer, stake, or payment functionality is included.** Rolls are requested through WoW's built-in server roll API. Both participants need version 1.3.0. This build has passed Lua syntax and simulated gameplay tests; live WoW Forever testing is still necessary.
