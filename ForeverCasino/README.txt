FOREVER CASINO 1.4.0 -- WOW FOREVER

Coin Toss: best of 1, 3, or 5. Deathroll: alternate d1000 -> last result until somebody rolls 1 and loses.
Solo: play both Side A and Side B. Two-player: challenge, accept, both Ready, and play.
An optional draw requires agreement by both players.

NEW: Results are generated locally by a private pseudorandom generator, without the server /roll function. Both players see rolls via addon messages. This is a casual/trust-based game: locally generated results are NOT server-verified and can be manipulated by modified clients. No real-world or in-game value exchange functionality.

SCOREBOARD: Persistent wins/draws/losses per character. Separate Two Players and Solo (Side A viewpoint) records. Only completed matches count. Solo Side B victories are recorded as Side A losses. Draws are possible in two-player games by mutual agreement. Leaving a match does not affect the record.

INSTALLATION: Extract the ForeverCasino folder to World of Warcraft/_forever_/Interface/AddOns/. Restart the client and use /casino. Both players need version 1.4.0 for multiplayer; older versions use a different addon-message prefix. Click and drag the minimap icon to reposition. Enter via the 18+ self-confirmation.

Lua addons are client-side; this addon does not install server software or create a tamper-proof RNG.
